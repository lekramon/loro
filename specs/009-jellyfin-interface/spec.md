# Jellyfin-inspired application interface

User selected the previously reviewed Jellyfin/Scyfin reference. Supersedes the red/black marketing-style presentation in feature 008.

## Acceptance

- Use a compact application shell: persistent desktop navigation, top utility bar, charcoal surfaces and restrained violet/cyan accents; responsive light theme.
- Remove the oversized promotional hero. Setup and settings occupy the main workspace with normal-sized headings.
- Navigation exposes working setup/settings locations; any future library entry is clearly unavailable and cannot navigate to fake content.
- Show four wizard stages with the current stage identified. Preserve folder browsing/defaults, accepted quality choices, audio ranking, validation and conflict behavior.
- Preserve sun/moon controls, English/Brazilian Portuguese, theme/locale persistence and keyboard focus visibility.
- Small screens collapse the sidebar into a compact header without horizontal overflow.
- No API or database changes. Existing foundation OpenAPI contract remains authoritative.

## Verification

Production build, existing browser journeys, responsive screenshots of setup and saved settings, specification consistency, native preview rebuild. Linux container runtime behavior is unaffected and remains separately pending.
